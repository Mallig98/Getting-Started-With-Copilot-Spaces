# OctoAcme Project Management Docs

This folder contains the core project management guidance used by OctoAcme. These documents provide a simple, repeatable framework for planning, running, tracking, and improving cross-functional work from idea to release.

## Overview of OctoAcme project management processes

OctoAcme uses a lightweight, stage-based project management approach that keeps work aligned to customer value, clear ownership, and measurable outcomes. The process emphasizes:

- Customer-first delivery: prioritize value, usability, and meaningful outcomes
- Iterative execution: break work into small, testable increments
- Clear ownership: define role responsibilities and accountability early
- Data-informed decisions: validate progress and outcomes with metrics and feedback
- Continuous improvement: capture lessons learned and adapt the process over time

The lifecycle is organized into five major phases:

1. Initiation — validate the need, align stakeholders, and define a lightweight plan
2. Planning — turn the initiative into a scoped backlog, timeline, and delivery strategy
3. Execution — build, track, review, and manage delivery through day-to-day work
4. Release & Deployment — prepare, verify, and ship changes safely
5. Retrospective & Improvement — evaluate outcomes and apply lessons learned

Use this folder as the single entry point for OctoAcme's project management guidance. Keep the project charter and planning artifacts in sync with these documents, and add more process-specific content in the repo as the team evolves.
